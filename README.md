# テスト対策アプリ

現在制作中です。ぜひ開発にご協力ください！

## コマンド

開発サーバー

```
yarn install
yarn dev
```

## 問題管理

[このようなスプレッドシート](https://docs.google.com/spreadsheets/d/1j8_wUHwIRV2WNTMgw7zokCtawbfrgs-UdKdyL9NPus8/)
で問題を管理できます。

メールなどで連絡してもらえれば編集権限をつけます。

## クレジット

- [heroicons](https://heroicons.com/)
  本当にありがとうございます！

また、たーけの改変部分もMITライセンスで利用可能です。使用する際は、ライセンスファイルをよくご確認ください。

## 用語

- 問題データベース ... 問題ブロックのまとまり（スプレッドシート単位）。データベースIDで管理。
- 問題ブロック ... それぞれの問題のまとまり（シート単位）。blockIDで管理。
